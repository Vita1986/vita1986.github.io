1. Общие положения

Оператор — ИП Кувакин Виталий Александрович. Контакт для обращений о персональных данных: kuvakinnn1986@gmail.com.

«Травник» — бесплатный информационный справочник рецептов народной медицины. Мы уважаем вашу конфиденциальность и собираем минимально необходимые данные. Приложение не требует регистрации, не запрашивает имя, телефон, адрес или платёжные данные.

2. Какие данные обрабатываются

  • Мобильное приложение: рецепты загружаются с нашего сервера, поэтому при поиске на сервер передаётся текст запроса и технические данные соединения (IP-адрес, время запроса) — только чтобы найти и показать рецепты и защитить сервис от злоупотреблений. Текст запроса не записывается повторно в продуктовую аналитику. Для оценки работы приложения мы учитываем только факты запуска, завершения первого экрана, поиска без текста, просмотра растения или рецепта по обезличенному техническому коду, добавления или удаления из избранного без номера рецепта, перехода к офлайн-версии или поддержке проекта и класс ошибки без её текста. При первой установке учитывается только канал из ограниченного списка (RuStore, Google Play, AppGallery, прямая установка или другой магазин), без исходного имени установщика и рекламной кампании. Для аналитики создаётся отдельный случайный идентификатор установки, который не связан с идентификатором офлайн-активации и перед хранением на сервере заменяется псевдонимом. Регистрация не нужна, имя и телефон мы не запрашиваем. Список избранного и история просмотров хранятся только локально на телефоне. Рекламных трекеров в приложении нет.
  • Фотографии растений: при открытии справочника лицензированные изображения загружаются с серверов Wikimedia Commons. Этот сервис технически получает IP-адрес, время запроса и обычные данные сетевого соединения. Мы не передаём Wikimedia имя, телефон, текст поиска или список избранного.
  • Офлайн-версия («Рецепты без интернета»): после ввода кода активации база рецептов сохраняется в память телефона, и поиск работает без обращения к нашему серверу. На сервер уходит только сам код активации — для проверки и учёта количества устройств (не более трёх).
  • Telegram-бот: обрабатывается ваш Telegram-идентификатор, имя пользователя и текст запросов к боту — исключительно для ответа на запрос, работы избранного и добровольных рассылок (например, «Рецепт дня»), которые можно отключить в любой момент.
  • Веб-версия и сайт: стандартные технические журналы веб-сервера (IP-адрес, время запроса) — для защиты от злоупотреблений и поддержания работы сервиса.

3. Платежи

Сам справочник бесплатен. Платными являются только офлайн-версия базы («Рецепты без интернета») и добровольные пожертвования — они оплачиваются в Telegram-боте через платёжные сервисы Telegram Stars и ЮKassa. Мы не получаем и не храним данные ваших банковских карт — оплата проходит на защищённой стороне платёжного сервиса. Для отправки кассового чека (54-ФЗ) бот один раз спрашивает адрес электронной почты; он используется только для чека.

4. Передача данных третьим лицам

Когда вы пользуетесь ботом, сообщения и идентификатор обрабатывает Telegram. При оплате сведения о платеже получает выбранный платёжный сервис. При загрузке фотографий с Wikimedia Commons запрос к этому сервису включает обычные сетевые данные, в том числе IP-адрес. Голосовой поиск использует службу распознавания на устройстве. Обработка речи зависит от её настроек; в поиск «Травника» передаётся распознанный текст.

5. Хранение и удаление

Основной сервер и базы данных сервиса размещены у HOSTKEY в Нидерландах. После переноса сохраняются технические резервные копии. Для аналитики используется случайный идентификатор установки. При активации офлайн-пакета сервер проверяет код и связывает доступ с устройством.

Чтобы запросить удаление связанных с вами данных, напишите на kuvakinnn1986@gmail.com с темой «Удаление данных Травника». Укажите, какой частью сервиса вы пользовались: приложением, ботом или офлайн-пакетом. Для поиска записи может потребоваться идентификатор установки или обращение из того же Telegram-аккаунта. Сведения о совершённых платежах хранятся в течение срока, установленного законом. Избранное и историю, сохранённые только на вашем устройстве, можно удалить очисткой данных приложения.

6. Медицинский дисклеймер

Информация в «Травнике» носит справочный характер и не является медицинской рекомендацией или услугой. Рецепты народной медицины не заменяют визит к врачу и назначенное лечение. При заболеваниях и наличии противопоказаний обращайтесь к специалисту.
